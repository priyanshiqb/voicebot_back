# Onboarding Webhooks API

This document details the server-to-server webhook endpoint exposed to Razorpay.

---

## 🔌 1. Razorpay Webhook Handler

* **Path**: `/api/v1/onboard/webhook/`
* **Method**: `POST`
* **Authentication**: Razorpay Cryptographic Signature Header (`X-Razorpay-Signature`)
* **Description**: Receives real-time asynchronous event updates from Razorpay (such as `payment.captured`). Validates signature authenticity, logs the raw request details, and automatically performs post-payment onboarding actions (creating tenant, user profile mapping, etc.) if they were not already completed by the client interface.

### Headers

| Header | Required | Description |
| :--- | :--- | :--- |
| `X-Razorpay-Signature` | Yes | HMACS-SHA256 signature generated by Razorpay using your configured webhook secret key. |

### Responses

#### 200 OK (Success)

Indicates that the event has been successfully received, validated, and processed (or logged).

```json
{
  "status": true,
  "message": "success",
  "data": null,
  "errors": null
}
```

#### 400 Bad Request (Signature Verification Failed)

Returned if the `X-Razorpay-Signature` is missing or cryptographically invalid.

```json
{
  "status": false,
  "message": "unauthorized",
  "data": null,
  "errors": ["SIGNATURE_CHECK_FAILED"]
}
```
