# In-App Notification API Documentation

Provides a personalized, in-app inbox of notifications for users. These endpoints power the "Notification Center" (e.g. the bell icon) in the UI. Unlike the system's outbound delivery ledger (`NotificationLog`), this API maps exactly one row per user and tracks individual read states.

Three things shape every endpoint on this page:

- **You only ever see your own notifications.** The list, retrieve, and mark-read endpoints are all heavily filtered to the authenticated user. There is no way for one user to enumerate or view another user's notifications.
- **Content is read-only.** Titles, bodies, and types are generated by the system backend (e.g., when a booking is confirmed or canceled). You cannot `PUT` or `PATCH` to change the text of a notification.
- **Idempotency.** Marking a notification as read that is already read will silently succeed (returning 200 OK) without modifying the `read_at` timestamp again.

> **VB_AGENT access:** none. Notifications are designed for human operators using the UI; a machine caller does not have an inbox.

## Endpoints Summary
- `GET /api/v1/core/in-app-notifications/` - List your notifications (paginated)
- `GET /api/v1/core/in-app-notifications/{id}/` - Retrieve a specific notification
- `POST /api/v1/core/in-app-notifications/{id}/mark-read/` - Mark one notification as read
- `POST /api/v1/core/in-app-notifications/mark-all-read/` - Mark all your unread notifications as read

**`PUT`, `PATCH`, and `DELETE` are not routed** — the viewset allows only `GET` and specific `POST` actions. Attempting them returns **405 Method Not Allowed**.

## Endpoint Details

### 1. List In-App Notifications

Every notification the authenticated user has received, newest first. Used to populate the notification tray/dashboard.

- **Path**: `GET /api/v1/core/in-app-notifications/`
- **Headers**: `Authorization: Bearer <token>`
- **Query Parameters**:

| Parameter | Type | Description | Validation |
|---|---|---|---|
| `page` | integer | Page number. Default `1`. | Out-of-range page → **404**. |
| `page_size` | integer | Rows per page. Default `10`. | Capped at `100`. |
| `search` | string | Full-text search term. | Matches against `title` and `body`. |
| `is_read` | boolean | Filter by read status. | `true` or `false`. Non-boolean → **400**. |
| `notification_type` | string | Filter by event type. | E.g. `CONFIRMATION`, `CANCELED`, `REMINDER`, or `REPORTS` — a [campaign report](campaign_report.md) is ready or has failed. |
| `ordering` | string | Sort field. Default `-created_at`. | Allowed: `created_at`, `read_at` (prefix `-` for desc). |

- **Success Response (200 OK)**:
  ```json
  {
    "status": true,
    "message": "success",
    "data": [
      {
        "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
        "title": "Your booking is confirmed",
        "body": "Event: Strategy Meeting\nWhen: 2026-09-01 14:00 UTC\nStatus: Confirmed",
        "notification_type": "CONFIRMATION",
        "is_read": false,
        "read_at": null,
        "created_at": "2026-08-18T10:00:00Z"
      }
    ],
    "errors": null,
    "meta": { "count": 1, "next": null, "previous": null, "page": 1, "page_size": 10 }
  }
  ```

| Status | When | `message` |
|---|---|---|
| **200** | Zero or more rows. Empty array is normal if the user has no notifications. | `success` |
| **401** | Missing or invalid token. | `Authentication credentials were not provided.` |


### 2. Retrieve In-App Notification

Fetches the full details of a specific notification belonging to the user.

- **Path**: `GET /api/v1/core/in-app-notifications/{id}/`
- **Headers**: `Authorization: Bearer <token>`

- **Success Response (200 OK)**:
  ```json
  {
    "status": true,
    "message": "success",
    "data": {
      "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
      "is_active": true,
      "created_at": "2026-08-18T10:00:00Z",
      "updated_at": "2026-08-18T10:00:00Z",
      "user": {
        "id": "123e4567-e89b-12d3-a456-426614174000",
        "email": "user@example.com",
        "first_name": "John",
        "last_name": "Doe"
      },
      "title": "Your booking is confirmed",
      "body": "Event: Strategy Meeting\nWhen: 2026-09-01 14:00 UTC\nStatus: Confirmed",
      "notification_type": "CONFIRMATION",
      "is_read": false,
      "read_at": null
    },
    "errors": null,
    "meta": null
  }
  ```

| Status | When |
|---|---|
| **200** | Notification retrieved successfully. |
| **404** | Notification ID doesn't exist, or belongs to a different user. |


### 3. Mark Single Notification as Read

Updates a specific notification's `is_read` flag to `true` and sets `read_at` to the current time. If already read, silently succeeds without modifying the timestamp.

- **Path**: `POST /api/v1/core/in-app-notifications/{id}/mark-read/`
- **Headers**: `Authorization: Bearer <token>`
- **Request Payload**: None required.

- **Success Response (200 OK)**:
  Returns the fully updated record.
  ```json
  {
    "status": true,
    "message": "success",
    "data": {
      "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
      "is_active": true,
      "created_at": "2026-08-18T10:00:00Z",
      "updated_at": "2026-08-18T12:00:00Z",
      "user": { ... },
      "title": "Your booking is confirmed",
      "body": "Event: Strategy Meeting\nWhen: 2026-09-01 14:00 UTC\nStatus: Confirmed",
      "notification_type": "CONFIRMATION",
      "is_read": true,
      "read_at": "2026-08-18T12:00:00Z"
    },
    "errors": null,
    "meta": null
  }
  ```

| Status | When |
|---|---|
| **200** | Notification marked read successfully (or was already read). |
| **404** | Notification ID doesn't exist, or belongs to a different user. |


### 4. Mark All Notifications as Read

Bulk action to mark every unread notification belonging to the current user as read.

- **Path**: `POST /api/v1/core/in-app-notifications/mark-all-read/`
- **Headers**: `Authorization: Bearer <token>`
- **Request Payload**: None required.

- **Success Response (200 OK)**:
  ```json
  {
    "status": true,
    "message": "success",
    "data": {
      "updated_count": 5
    },
    "errors": null,
    "meta": null
  }
  ```

| Status | When |
|---|---|
| **200** | Successfully marked all unread items as read (returns `0` if none were unread). |
